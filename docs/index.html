      Does it actually catch anomalies?

      Real market anomalies have no labels, so we plant known ones: price spikes, volume bursts with flat prices, volatility blow-outs and pump-and-dumps. Each detector is then scored on held-out data it never trained on.

      How it works

      1. Collect. Every hour, GitHub Actions pulls 90 days of hourly candles for 8 coins from the public Coinbase Exchange API.
      2. Normalise. Returns, dollar volume, high-low range and order flow become robust z-scores against the previous week, so every coin shares one scale with no look-ahead.
      3. Learn normal. A 2-layer LSTM autoencoder in PyTorch compresses each 24-hour window to 16 numbers and rebuilds it. It retrains weekly.
      4. Score. The model is exported to ONNX and scored with onnxruntime. Severity is reconstruction error divided by the 99th percentile seen on validation data.
      5. Explain. The feature with the largest error names the tremor: price move, volume burst, volatility or buying and selling pressure.
      6. Publish. This page rebuilds on GitHub Pages. The same model ships as a FastAPI Docker image.
      Market data from the Coinbase Exchange public API. Educational project; not investment advice.
